### Situación
A developer is building an application that uses AWS [[API Gateway]] APIs, AWS [[Lambda]] functions, and AWS [[DynamoDB]] tables. The developer uses the AWS Serverless Application Model (AWS [[Serverless App Model|SAM]]) to build and run serverless applications on AWS. Each time the developer pushes changes for only to the Lambda functions, all the artifacts in the application are rebuilt.  
  
The developer wants to implement AWS SAM Accelerate by running a command to only redeploy the Lambda functions that have changed.  
  
Which command will meet these requirements?

- A. sam deploy --force-upload
- B. sam deploy --no-execute-changeset
- C. sam package
- D. sam sync --watch
